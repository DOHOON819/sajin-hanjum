# 사진한줌

서버에 사진을 전송하지 않고 브라우저에서 사진 크기·용량·형식을 조절하는 한국어 도구입니다.

- JPG/PNG/WebP 입력과 출력, 비율을 유지하는 축소
- 목표 용량을 위한 화질·크기 조절
- 12장까지 순차 처리, 개별 저장 및 UTF-8 파일명을 지원하는 ZIP
- 원본 파일을 변경하지 않으며 분석·광고·외부 라이브러리 요청 없음
- 모바일·키보드 사용 지원, 오류·미지원 형식·커진 결과 안내

## 실행

Node.js에서 `npm run dev` 실행 후 http://127.0.0.1:4173 열기. 런타임 의존성이나 API 키가 없습니다.

`npm test`로 크기 계산, 파일명 처리, ZIP 생성 검증. `dist/` 디렉터리를 정적 호스팅에 배포할 수 있습니다.

## 범위

HEIC, RAW, SVG, GIF 미지원. 애니메이션 PNG/WebP는 정지 이미지가 될 수 있습니다. 파일당 25MiB·3천만 화소 제한. JPG 투명 부분은 흰색. 변환 결과에는 원본 EXIF/GPS 정보를 복사하지 않습니다. 브라우저 인코더에 따라 색상·화질·용량이 달라질 수 있습니다.

광고·결제 연결은 아직 없으며 수익화 완료를 의미하지 않습니다. 배포 전 상업적 이용이 허용되는 호스팅을 선택하고 실제 공개 주소로 canonical과 sitemap을 설정하세요.
